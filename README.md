# Hangman
A simple, responsive hangman game. Built with clean JavaScript + HTML + CSS.
Array of words declared in external JS file [variables.js].

Feel free to modify the word list to load from a .txt file if desired.

## How to Play
1. A random word will be selected
2. Guess letters one by one
3. You have 8 wrong guesses before game over
4. Correctly guess all letters to win!
